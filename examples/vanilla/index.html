@anil-labs/validator

Framework-free. Works with plain TypeScript, any framework, or straight from a CDN.

This page uses the workspace build. To use it with no build step at all, drop in the CDN global: 

<script src="https://unpkg.com/@anil-labs/validator"></script>
<script>
  const { Validator, validation } = window.Validator
</script>
